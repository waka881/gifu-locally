# Gifu Gourmand

Source for [Gifu Gourmand](https://gifugourmand.com/), an English travel guide to Gifu, Japan: Takayama, Shirakawa-go, Gero Onsen, Gujo Hachiman and day trips from Nagoya. Articles live in `articles/` as Markdown; `site/build.py` turns them into a static site, deployed to GitHub Pages on every push to `main`.

Only articles with `status: 公開` are published.
